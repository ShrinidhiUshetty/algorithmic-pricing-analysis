# Project Notebooks

This folder contains the Jupyter Notebook files used in the Algorithmic Pricing Analysis project.

## Notebooks

1. 01_data_cleaning.ipynb - Data cleaning and preprocessing.
2. 02_exploratory_data_analysis.ipynb - Exploratory data analysis and visualization.
3. 03_pricing_impact_analysis.ipynb - Analysis of pricing changes and their impact on sales and revenue.

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
