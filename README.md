# Algorithmic Pricing Analysis

## Project Overview
This project analyzes how pricing changes relate to sales and revenue using data analytics techniques.

## Objectives
- Clean and prepare sales transaction data.
- Analyze pricing, sales quantity, and revenue trends.
- Identify patterns across products and time periods.
- Visualize findings using Python and interactive dashboards.
- Explore the potential impact of pricing changes.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit
- GitHub
